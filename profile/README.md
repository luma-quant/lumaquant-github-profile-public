## Claim discipline

We distinguish source-backed facts, time-bound on-chain observations,
operator-declared policy and limitations. We do not describe unaudited code as
independently audited, promise investment returns, call LUMA supply fixed while
mint authority remains active, or describe real payments or token delivery as
enabled when those execution rails are excluded.
